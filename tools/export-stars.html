Chrysanthemum

A gentle backup of every star

Private memories

The backup file contains your memories in plain, readable text. Keep it somewhere only the two of you can reach, and never post it or commit it to GitHub.

This page only reads the database. It cannot change or delete anything. It talks only to your login Worker (to check the shared password) and to Google's Firebase (to sign in and read). The file never leaves this device unless you move it.

Unlock

Enter the same shared password as the website.

Back up

Reads the stars collection, checks the copy, then lets you save it as a JSON file.

Save

Each save uses a new file name, so an earlier backup is never replaced by this page. Your browser may still add “(1)” if you save the same file twice.

Check the file I saved

A download can fail without any warning (full storage, interrupted transfer). Pick the saved file here and it will be re-read and compared with what was verified above.

What this does and does not prove

  • It reads every document the database returns for stars, in pages, and compares the total with the database's own count taken right afterwards.
  • A matching count is a consistency check, not a guarantee. If a memory was added while reading, the numbers can differ — just run it again.
  • Document IDs, all fields (including ones this page has never heard of), timestamps and links are copied as they are. Firestore's hidden creation/update times are not available to a web page and are not included.
